# Noah Chung Portfolio

A static portfolio site for GitHub Pages. No build step or dependencies are required.

## Publish with GitHub Pages

1. Create a GitHub repository named `noahchungus.github.io` to publish at `https://noahchungus.github.io/`.
2. Upload this folder's contents to the repository root, including the `assets` folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main`, and choose the `/ (root)` folder.
5. Save. GitHub will publish the site shortly afterward.

For a project repository with another name, GitHub Pages will publish at `https://noahchungus.github.io/<repository-name>/` instead.

## Update content

- Replace the image at `assets/noah-chung-headshot.png` to change the portrait.
- Replace `assets/noah-chung-resume.pdf` to update the résumé download.
- Edit the second project card in `index.html` once the next project is ready.
